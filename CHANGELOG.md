# Changelog

## 0.1.0 · 15 ottobre 2026

Prima versione.

- Dashboard con schede per i sensori scelti tra quelli di LibreHardwareMonitor, letti dal suo web server locale.
- Valore colorato secondo le soglie, barra con fascia min–max e tacche delle soglie, mini grafico degli ultimi due minuti.
- Scheda CPU con core più caldo, media e più freddo e scelta dei core.
- Nomi personalizzati, ordine delle schede, tema chiaro/scuro/sistema, finestra in primo piano.
- Avvio automatico di LibreHardwareMonitor se non è già aperto.
